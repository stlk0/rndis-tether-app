# Security

RNDIS Tether can install the rndis-tether service with administrator rights and changes
its settings through the service's admin socket. Please report security problems
privately through GitHub: open the repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue for them.

Problems in the service itself belong to
[rndis-tether](https://github.com/stlk0/rndis-tether/security).
